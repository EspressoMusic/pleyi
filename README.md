# English Play

פלטפורמה למורה פרטי ותלמיד — מתחברים לחדר ומשחקים משחקי אנגלית בזמן אמת, בעיצוב בסגנון Linky.

## התקנה והרצה

```bash
npm install
npm start
```

פתחו בדפדפן: **http://localhost:3456**

## איך משתמשים

1. **מורה** — לוחץ "אני מורה — צור חדר", מזין שם, מקבל קוד בן 6 ספרות
2. **תלמיד** — לוחץ "אני תלמיד — הצטרף", מזין שם וקוד
3. **מורה** בוחר משחק — שניכם רואים את אותו מסך

## קביעת תור ותשלום

1. **תלמיד** — גולל ל"קביעת תור", בוחר תאריך ושעה, ממלא פרטים ומשלם
2. **מורה** — נכנס ל"יומן מורה" (קוד: `teacher2026`) או בלשונית "יומן תורים" בחדר
3. רואה את כל התורים בזמן אמת — שם, מייל, טלפון, סטטוס תשלום

### הגדרות (קובץ `data/settings.json`)

| שדה | ברירת מחדל |
|-----|------------|
| `teacherPin` | `teacher2026` |
| `pricePerLesson` | 150 ₪ |
| `workingDays` | א'-ה' (0-4) |
| `workingHours` | 09:00–20:00 |

> התשלום כרגע במצב **הדגמה** (מדומה). לחיבור Stripe אמיתי — הגדירו `STRIPE_SECRET_KEY`.

## ניהול תלמידים

**`/admin/students`** — נכנסים עם קוד המורה (`TEACHER_PIN`), פותחים תיק לכל תלמיד ונותנים שיעורי בית מתוך התרגילים של "לומדים אנגלית".
לכל תיק יש קישור אישי סודי (`/s/<key>`) ששולחים לתלמיד — בלי הרשמה ובלי Google. התלמיד רואה בו את שיעורי הבית, וכל מה שהוא פותר (גם תרגול חופשי ומשחקים) נשמר בתיק: ציונים, טעויות, התקדמות לפי נושא, ולצידם יומן הערות של המורה.
בפרודקשן צריך את `FIREBASE_SERVICE_ACCOUNT` (ראו `FIREBASE_SETUP.md`), אחרת הנתונים נשמרים בקובץ מקומי שנמחק בכל פריסה.

### נקודות וטבלת שיאים

כל סבב שתלמיד מסיים דרך הקישור האישי מזכה אותו בנקודות (`lib/student-progress.js`): כל תשובה נכונה שווה 10 נקודות ברמה 1, 15 ברמה 2 ו-20 ברמה 3 (קטעי קריאה ברמה 4: 25). סבב בלי טעויות מוסיף 20 נקודות, תרגול טעויות שווה חצי, ומשחקים נותנים 5 נקודות לתשובה נכונה ועוד 10 לכל כוכב.
טבלת השיאים היא לכל כיתה, כלומר לכל התלמידים של אותו מורה, והיא מוצגת עם הנקודות של השבוע (מתאפסות ביום ראשון) ועם הנקודות של כל הזמנים. התלמידים רואים אותה בדף "לומדים אנגלית" ובדף שיעורי הבית שלהם, עם שם פרטי ואות ראשונה של שם המשפחה. המורה רואה אותה עם השמות המלאים ב-`/admin/students`.

### רמות וסוגי תרגילים

כל תרגיל משויך לרמה 1 (קל), 2 (בינוני) או 3 (מתקדם), ובדף הנושא התרגילים מסודרים לפי הרמות. `public/js/english-more.js` בונה לכל נושא תרגילים נוספים מהתוכן שכבר קיים בו: מציאת טעות, בחירת המשפט הנכון, בניית מילה מאותיות והכתבה. בנושאים שיש בהם מילים עם תמונות הוא בונה גם נכון/לא נכון עם תמונה, תרגום לשני הכיוונים והתאמה בין אנגלית לעברית.
